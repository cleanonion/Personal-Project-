# Quiet Gravity - 90-Day Personal Growth App

A mobile-first personal growth web app with:

- 90 numbered days
- Daily 20-minute curriculum
- Confidence, charm, presence, communication, emotional control, leadership, discipline, and identity work
- Notes for every day
- Completion tracking
- Streak and progress tracker
- Export notes
- Browser local storage

## How to use with GitHub Pages

1. Create a new GitHub repository.
2. Upload these files:
   - index.html
   - style.css
   - script.js
   - README.md
3. Go to Settings > Pages.
4. Under Branch, select `main` and `/root`.
5. Save.
6. Open the GitHub Pages link from Safari.
7. Tap Share > Add to Home Screen.

Your progress saves in the browser on the device you use.
